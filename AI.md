## Project 1

### Which tools did you use?

- Claude

### What did you use them for?

- Explaining functions / debugging code

### How did you use them?

- I told Claude from the beginning that it shouldn't write the code for me, but only give me hints on how to do it myself. I needed the most help with the shape of the leaves and the branches and for some bug fixes in the end.

### What was your own contribution?

- The whole idea, concept and design choices are my own. I drew a sketch first of how I wanted it to look in the end and mostly stuck to it. I only used AI when I was stuck and needed it to explain to me how to code something.

### Reflection

- I think it worked pretty well, because it still feels completely like my own project, and I learned a lot about writing the code myself, since I mostly used AI to explain things to me, not to write the code for me.

## Project 2

### Which tools did you use?

- Claude

### What did you use them for?

- Generating the csv. with an estimated number of currently 16,000 pigeons in Zurich that I researched myself
- Writing code / debugging code

### How did you use them?

- I mostly used it to design the interface faster and to try out several different ideas without coding them myself for hours. That way, I was able to make it look the way I had initially imagined. I needed the most help with designing the shape of the pigeons and implementing the effects and interactions.

### What was your own contribution?

- The whole idea, concept and design choices are my own. I did the steps before the design on my own with very little help: the functions and the logic behind the visualization.

### Reflection

- It was very helpful for me, and it made it possible to implement the idea I had in mind without spending a whole day trying to shape a pigeon myself. I could just explain how I wanted it, make a sketch, let it do its thing and then correct it a few times since I still didn't like it for a while.
